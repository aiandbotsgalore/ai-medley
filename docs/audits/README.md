# Audit Archive

Every file in this directory is a dated evidence record, not a current operating
guide or active task list. Audit findings are intentionally preserved as they
were observed, even when later work changed the workflow.

Use these files for the current project truth:

- `docs/current-operations.md` — implemented runtime behavior and operating
  procedures.
- `AGENTS.md` — non-negotiable product and engineering rules.
- `task_plan.md` — current work and exact next actions.
- `docs/architecture/medley-workflow-visual-guide.md` — current Automatic v4
  workflow.

The misleadingly named `current-workflow-root-cause-audit.md` is a historical
audit of the repository at commit `546287cf` on 2026-06-23. It is not current.

Never execute old model, provider, fallback, rendering, review, or finalization
instructions from an audit without first confirming them against the current
documents above.
