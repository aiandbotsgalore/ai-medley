# Plan Archive Status

The dated implementation plans in this directory are historical design and execution records. They are retained for provenance and must not be treated as the current runtime contract when they conflict with code, tests, or `docs/current-operations.md`.

Do not delete or rewrite these plans to make past assumptions appear current. Add a new dated plan or audit record for future work. The `archive/` subdirectory contains plans already classified as superseded; other dated plans may also describe completed or superseded implementations even when their original task checklists remain visible.
